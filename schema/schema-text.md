# Template Schema

The template schema is used as a basis for creating new schemas. The schema should include a description, followed by all of the entities (classes, properties, etc.) that are part of the schema. These should be populated using the rules like the one below (see the [Schema User Guide](../schema-user-guide.md) for a complete list of rules and their usage).

${rules.all}

For an example of a schema, see the LDAC schema: [w3id.org/ldac/terms](https://w3id.org/ldac/terms)
